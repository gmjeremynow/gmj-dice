# GM Jeremy's Critical Hit Dice

A Foundry VTT module that adds three custom six-sided dice, each with picture faces and a 3D look through [Dice So Nice!](https://foundryvtt.com/packages/dice-so-nice).

| Die | Chat command | Formula | Faces |
|---|---|---|---|
| Critical Hit (black) | `/crit` | `1dh` | Stun, Double Damage, Sever Limb, Max Damage, Triple Damage, Death |
| Fumble (orange) | `/fumble` | `1du` | Drop Weapon, Fall, Break Weapon, Hit Self, Hit Ally, Knocked Out |
| Hit Location (gray) | `/location` | `1db` | Head, Torso, Right Arm, Left Arm, Right Leg, Left Leg |

## Classic Polyhedral Set

A multicolor set of standard dice for Dice So Nice!, based on a classic set bought at Gary Con. To use it, open Dice So Nice! settings and choose **GM Jeremy's Classic Set** under Dice Presets (Faces).

| Die | Color |
|---|---|
| d4 | Yellow |
| d6 | Coral orange |
| d8 | Green |
| d10 | White |
| d12 | Light blue |
| d20 | Red |
| d100 (tens) | Black with white numbers |

By default the Classic d10 and d100 are drawn on a 20-sided model numbered 1-0 twice, like old-style dice. This is experimental: it relies on Dice So Nice! internals and falls back to normal 10-sided dice if they change. Turn it off with the client setting "Show Classic d10 and d100 as 20-sided dice".

## Zocchihedron

A single silver 100-sided die shaped like a golf ball, inspired by Lou Zocchi's Zocchihedron. Roll it with `/zocchi`, the "Roll Zocchihedron" macro, or the formula `1dz`. The command and macro wait for the ball to stop before posting; a typed formula posts right away while the ball rolls. Normal `1d100` rolls still use two dice.

The 3D model needs Dice So Nice! 6.3.0 or later. The model, collision shape and rotation table are generated by `tools/build_zocchi.py` (Python with numpy, scipy and Pillow); `tools/render_zocchi.py` renders a quick preview.

## Features

- **Chat commands** roll the die, wait for the 3D animation, then post a card with the face image and name.
- **Sever Limb** on the Critical Hit die automatically rolls the Hit Location die.
- **Macros** for the three special dice, plus 1d20, 1d12, 1d10, 1d8, 1d6, 1d4, 1d100 and the Zocchihedron, are created in the Macro Directory the first time a GM loads the world. Turn this off in the module settings with "Create macros automatically".
- **Roll formulas** (`/r 1dh`, `/r 1du`, `/r 1db`) work anywhere Foundry accepts a formula. These show the face image in the roll tooltip but do not post a card or trigger follow-up rolls.

## Macro API

```js
const api = game.modules.get("gmj-dice").api;
api.rollCriticalHit();
api.rollFumble();
api.rollHitLocation();
api.rollZocchihedron();
```

## Requirements

- Foundry VTT v12 or later (verified on v14)
- Dice So Nice! (optional, recommended) for 3D dice

## Customizing

Face order, colors, commands and follow-up rolls are set in the `DICE` and `FOLLOW_UPS` tables at the top of `scripts/main.js`.
